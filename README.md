

# Online Ads ROI & Conversion Modeling Sandbox

A structured simulation and decision framework for **online advertising budget allocation** and **ROI / conversion optimization**, inspired by Google Ads–style media mix and bidding systems.

The project serves as a **research and prototyping sandbox** for reasoning about large-scale ad spend decisions across channels such as Search, Display, and Video.

---

## Project Purpose

This repository explores how **business advertising questions** can be translated into **explicit computational structures**, including:

- Converting ROI, CAC, and budget constraints into model states and objectives
- Analyzing conversion funnels and cross-channel spend trade-offs
- Prototyping an **agent-based / agentic AI-style ads ecosystem** that reasons about:
  - budget allocation schedules
  - marginal ROI per channel
  - risk–reward profiles of different spend paths

All artifacts are designed to be **human-readable and LLM-readable**, enabling future automation or agent orchestration.
